There are a few ways to install this mod.

First, if you have the Deltarune mod manager Deltamod (https://gamebanana.com/tools/20575), you can just import it into there via the zip file this README is located in.

Second, you can use DeltaPatcher (https://www.romhacking.net/utilities/704/) with the four .xdelta files in this folder. For each chapter, have the "Original file" be the data.win for that chapter and the "XDelta patch" be the corresponding .xdelta file, then apply the patch.

Finally, in the ScriptResources subfolder are some files and a .csx script. For each chapter, load its data.win file in UTMT, and then go to "Scripts" -> "Run other script..." in the top left utility bar and choose the .csx file. After the script is done, save the data.win file for that chapter. (For reference, the .csx script was created in UTMT v8.3.0.)
